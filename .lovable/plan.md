# Website animation polish

## Goal
Keep the current DigiBasera design and content unchanged while improving motion throughout the site and adding a relevant animated background to the Contact page heading area.

## Changes
- Audit existing motion patterns and reuse the current animation library and styling system.
- Add subtle entrance, hover, and section transitions without changing layout, copy, colors, or functionality.
- Add a lightweight digital-network style animated background behind the Contact page heading, keeping text readable.
- Respect reduced-motion settings and avoid performance-heavy effects on mobile.
- Verify the homepage and Contact page on desktop and mobile, including navigation and forms.

## Technical details
- Use existing React motion utilities and semantic theme colors.
- Keep decorative animation non-interactive and hidden from assistive technology.
- Do not introduce new content, backend changes, or replace existing media.
